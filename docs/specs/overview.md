# 利用者・画面・データの共通仕様

更新日：2026年11月19日（日本時間）

既存の実装引継ぎ資料0.6版からの整理。今回の移行は仕様変更・個別作業の承認を意味しない。段階2の候補は採用決定まで初回の実装対象に含めない。

## 利用者別の体験

以下は段階2までの体験の全体像。段階1では差し戻し・再提出を除く主要な流れを試す。

### 社長

依頼を受けたら案件を仮登録する。未割当の一覧と担当別予定を見て、日時・担当を決める。施工後は未報告の案件を把握し、提出された報告を確認する。不足は理由を添えて差し戻す。

### 作業員

自分の今日の案件を開き、現場情報・依頼内容・注意事項を確認する。施工中または施工後に写真と結果を保存し、報告を提出する。差し戻しがあれば理由を確認して修正・再提出する。

役割切替は操作体験のための疑似機能であり、アクセス制御を保証するものではない。

## 画面構成

以下は段階2までを含む画面候補。段階1では検証課題を進められる最小限の構成にする。A02の新規登録・検索、A04の差し戻し、W02の複数台・チェック・追加内容等は段階2の採用判断に従う。

| ID | 画面 | 主な内容・操作 |
| --- | --- | --- |
| A01 | 予定・割当 | 初期表示。今週／前週／翌週、担当別の予定、未割当案件、日時・担当編集 |
| A02 | 案件一覧 | 元請け・工事状況・報告状況で絞込、氏名・受付番号・現場名で検索、新規登録 |
| A03 | 案件詳細 | 元請け、訪問先、工事内容、機器、日時・担当、注意事項、報告状況 |
| A04 | 報告確認 | 未報告／確認待ち／差し戻し／確認済み、報告詳細、確認・差し戻し |
| W01 | 今日の案件 | 作業員選択、日付変更、自分の案件、訪問時間と住所、差し戻し表示 |
| W02 | 作業・報告 | 機器別写真、チェック、型番・製造番号、作業結果、追加内容、下書き・提出 |

詳細や編集はモーダルまたはサイドパネルでもよく、画面数は実装上のページ数を強制しない。スマホでは予定表を横に縮小せず、日単位のカード表示に切り替える。

## データ構成のたたき台

段階2までを含む候補であり、段階1に未採用のデータや入力項目の実装は要求しない。

論理的なデータ構成。実DBやAPIの採用を要求するものではない。

| データ | 主な項目 |
| --- | --- |
| 元請け | ID、名称、担当窓口メモ |
| 作業員（担当枠） | ID、表示名。初回は個人のみ。協力会社チーム区分や複数人割当は後続で検討 |
| 案件 | ID、元請けID、受付番号、訪問先名、現場名称、住所、連絡先、依頼内容、注意事項、工事状態、作成日時 |
| 予定 | 案件ID、工事日、開始時刻、終了時刻、担当枠ID |
| 機器 | ID、案件ID、設置場所、型番、製造番号 |
| 報告 | 案件ID、報告状態、下書きの作業結果、作業メモ、再訪問理由・対応、追加有無・内容、提出日時、確認日時、差し戻し理由 |
| チェック結果 | 機器ID、項目ID、結果、理由 |
| 写真 | ID、機器ID、写真区分、画像データ、追加日時 |

案件と機器は1対多、機器と写真も1対多。初版の報告は案件ごとに1つを編集する。複数版の履歴保存は対象外。時刻の表示と判定は日本時間に統一する。

# 保存・復元の仕様

更新日：2026年11月24日（日本時間）

既存の実装引継ぎ資料0.6版からの整理。今回の移行は仕様変更・個別作業の承認を意味しない。段階2の候補は採用決定まで初回の実装対象に含めない。

### 保存とデータの制限

- 構想資料のAWS構成は本番候補として保留し、今回の採用条件にしない。
- 写真を含むブラウザ内保存はIndexedDBを使う。保存に利用する補助ライブラリ・容量制限は実装時に明記する。
- 写真はJPEG／PNG／WebPを対象。HEIC等は初版対象外と明示。目安として1枚10MBまで、機器ごと10枚までとし、必要に応じ縮小して保存する。
- 保存失敗を通知し、保存に成功する前に「保存済み」と表示しない。リセット前は確認を挟む。
- 初回のみサンプルを作成し、再読み込みで編集内容を上書きしない。
- T005の新規案件は既存データを上書きせずに挿入し、同じブラウザの再読込後も保持する。登録中の再送信を抑止し、保存失敗時は入力を保持する。初期化を確定すると追加した案件も消去する。
- ブラウザの保存領域削除でデータが消える。実データの投入、本番認証、端末間共有を前提にしない。
- サーバーやアカウントを用意せず、ローカル確認可能な構成を基本とする。公開・外部サービス接続は別途検討する。

# 仕様一覧

仕様は「どう動くべきか」を管理する。目的・範囲は[引継ぎ資料](../prototype-handoff.md)、手順は[開発フロー](../development-workflow.md)、設計理由は[ADR](../adr/README.md)、結果は[作業記録](../tasks/README.md)を参照する。

| 仕様 | 対象 |
| --- | --- |
| [共通仕様](overview.md) | 利用者、画面ID、共通データと日本時間 |
| [予定・割当](scheduling.md) | 日時・担当、重複、案件登録の後続候補 |
| [案件確認・報告](reporting.md) | 写真、下書き、提出、管理者確認、状態遷移 |
| [保存・復元](storage.md) | 画像形式、制限、初期化、保存失敗 |
| [完成条件](acceptance.md) | P01〜P14と段階別の適用範囲 |

## 状態と更新

- 決定済み：既存資料・ユーザー判断に根拠がある内容。個別作業の承認とは区別する。
- 仮置き：人数・件数・所要時間・容量目安等、検証用の初期値。変更時に理由を記録する。
- 未決定：判断が必要な事項。推奨案と影響を用意する。
- 後続候補：段階2以降。記載があっても初回実装を要求しない。

2026年11月19日に引継ぎ資料0.6版の詳細を移行。記載済みのたたき台を一律に承認済みへ格上げしない。仕様変更時は対象作業と承認範囲を確認し、必要なら①・②の該当部分を再確認する。P01〜P14を再利用・振り直ししない。

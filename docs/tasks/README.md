## 記録方法

[テンプレート](template.md)をコピーし、`T001-topic.md`から連番で作る。全体の定義・設計・最終確認をまとめる親作業と、機能単位の子作業を必要に応じて関連づける。全体承認の対象に含まれる子作業は親の承認を参照し、通常は子ごとの人間承認を追加しない。

状態は未着手／進行中／人間確認待ち／修正中／最終確認待ち／完了／保留。現在工程①〜⑧も併記する。検証結果の合格／不合格／未実施／対象外とは混同しない。

作業終了・引継ぎで一覧と個別記録を更新する。別セッションには記録のパス、対象版、必要な仕様・ADRを渡す。会話履歴全体を前提にしない。全体の最終採用は⑧の判断後に記録する。

# 予定・割当の仕様

更新日：2026年11月24日（日本時間）

既存の実装引継ぎ資料0.6版からの整理。今回の移行は仕様変更・個別作業の承認を意味しない。段階2の候補は採用決定まで初回の実装対象に含めない。

### 案件登録

- T005では、管理者が元請けと現場名を入力する。現場住所と依頼メモは任意。前後の空白は除き、空白だけの必須項目は不足とする。同名の現場でも別の依頼を登録できる。
- 保存成功後は、案件一覧（A02）の先頭と予定・割当（A01）の未割当欄に表示する。初期状態は工事「未手配」、報告「未提出」、機器は1台。案件一覧には割当後の案件も残る。
- メール・LINEの内容は依頼メモに手動で転記する。連絡先・受付番号・原本添付・請求先の扱いは後続候補とする。

### 日程・担当の割当

- ドラッグ操作を必須にしない。案件から編集フォームを開き、日時と担当を選べればよい。
- 予定確定には現場住所、工事日、開始・終了時刻、担当が必要。T005ではA01・A02から開く同じフォームで、住所が空の案件に住所の必須欄を表示し、日時・担当と同時に保存する。
- 終了時刻は開始時刻より後。同日内の工事のみを仮定する。
- 同じ担当で時間が重なる場合は、該当案件を表示して保存を止める。
- 重複判定は `開始A < 終了B かつ 開始B < 終了A`。終了と次の開始が同時刻なら重複としない。
- 移動時間、休憩、休日、担当者の出勤可否は自動判定しない。この限界を予定画面に短く示す。
- 日時または担当が未設定の案件は未割当として扱う。
